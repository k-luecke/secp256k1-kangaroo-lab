# Preregistration: Discovery Cycle 1 (X-Only Negation-Quotient BSGS)
Hypothesis ID: H-DISC-01
Laboratory: Lab B (Bounded secp256k1)
Target: Test whether factoring out the negation automorphism iota(P) = -P via x-only matching reduces baby-step table size and setup time by ~50% with exact O(1) sign resolution.
Falsifier: Table collisions outside +/- P, unresolvable sign ambiguity, or T_cold fails to beat standard BSGS.
